# CLAUDE.md

This file provides guidance when working on Campus Copilot.

## Product

Campus Copilot is a pedagogical assistant that helps students find and understand information in their training references, regulations, certification materials, and administrative documents. It can also support pedagogical staff when consulting the same corpus.

## Commands

```bash
npm run dev
npm run lint
npm run build
npm start
```

No automated test framework is configured.

## Stack

- Next.js 16 with App Router and React 19
- TypeScript and Tailwind CSS 4
- shadcn/ui and Radix UI
- Zod validation
- Mistral Chat Completions through server-side REST calls
- React Markdown with GFM support
- Mustache for controlled documentary-context templates

## Architecture

- `app/api/chat/` — validates conversations, handles small talk, retrieves context, calls Mistral, and returns answers with sources.
- `components/chat/` — chat interface, Markdown rendering, messages, input, and source display.
- `components/documents/` — indexed-document summaries displayed on the home page.
- `components/layout/` — shared header, footer, navigation, and container.
- `components/ui/` — reusable shadcn/Radix primitives.
- `data/knowledge/` — statically imported JSON knowledge documents.
- `lib/hooks/` — client-side chat state and API calls.
- `lib/knowledge/` — deterministic chunking, normalization, and lexical retrieval.
- `lib/llm/` — system prompt, small-talk detection, Mistral REST client, and provider types.
- `types/chat.ts` — public message, response, and source contracts.

The `@/*` alias resolves from the repository root.

## Core rules

- Keep complete knowledge documents server-side. Only document summaries and selected source excerpts may reach the browser.
- Sources are generated by the API from retrieved chunks; Mistral must not create source objects.
- Keep Mistral credentials server-side under `MISTRAL_*`; never expose them through `NEXT_PUBLIC_*` variables.
- Markdown output must not interpret raw HTML. Do not add `rehype-raw` or `dangerouslySetInnerHTML`.
- Preserve the system prompt protections against invented information and instructions embedded in documents.
- The current scope has no database, embeddings, vector store, authentication, or document upload.
- Do not add infrastructure for those capabilities unless a later task explicitly changes the product scope.

## Environment variables

```env
MISTRAL_API_KEY=
MISTRAL_MODEL=mistral-small-latest
MISTRAL_BASE_URL=https://api.mistral.ai/v1
```

Legacy `LLM_*` names remain temporary server-side fallbacks. Never commit `.env.local` or print secret values.
